# ProofWork cloud

This folder is the account server for the phone app.

Masters and apprentices are not created here with a fixed password. They open the phone app and create their own email and password.

```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5057 on a phone browser, or point the Expo app at this computer's IP on port 5057.
